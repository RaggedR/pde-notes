# Klein Quartic (genus 3)

Cohomology of the Klein quartic via dual PSL(2,7) cell decompositions; the (2,3,7) triangle group gives the Hurwitz-maximal automorphism group of order 168. Research notes in [PRELIMINARY.md](PRELIMINARY.md).

- `klein_quartic_cohomology.py` — H¹ = V₃ ⊕ V̄₃, oriented Lefschetz traces
- `klein_quartic_3d.html` — Poincaré disk tiling + 3D genus-3 surface (built by `build_viz.py`)
- `triangle_group.py` — (2,3,7) triangle group machinery
- `verify_cohomology.g` — GAP verification
