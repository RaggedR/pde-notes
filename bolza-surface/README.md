# Bolza Surface Visualizations

Interactive visualizations of the Bolza surface, torus embeddings, and related algebraic geometry.

## Live Demos

| Visualization | Description |
|---|---|
| [Square to Torus (Clifford & Weierstrass)](https://raggedr.github.io/symmetric-graphs/bolza-surface/weird.html) | Flat square morphs into a torus via Clifford embedding (S³ stereographic projection) or Weierstrass ℘ (elliptic curve in C²) |
| [Square to Torus (basic)](https://raggedr.github.io/symmetric-graphs/bolza-surface/square_to_torus.html) | Simple square-to-torus morph |
| [Weierstrass ℘ Torus](https://raggedr.github.io/symmetric-graphs/bolza-surface/wp_torus.html) | Weierstrass ℘-function torus embedding |
| [Bolza 3D](https://raggedr.github.io/symmetric-graphs/bolza-surface/bolza_3d.html) | 3D visualization of the Bolza surface |
| [Bolza Octagon](https://raggedr.github.io/symmetric-graphs/bolza-surface/bolza_octagon.html) | Hyperbolic octagon fundamental domain |
| [Bolza Pipeline](https://raggedr.github.io/symmetric-graphs/bolza-surface/bolza_pipeline.html) | Full computation pipeline visualization |
| [Bolza R⁴ v3](https://raggedr.github.io/symmetric-graphs/bolza-surface/bolza_r4_v3.html) | R⁴ embedding (latest version) |
| [Octagon Folding](https://raggedr.github.io/symmetric-graphs/bolza-surface/bolza_folded6.html) | Animated octagon folding into genus-2 surface |
| [Wounded Torus](https://raggedr.github.io/symmetric-graphs/bolza-surface/wounded_torus.html) | Wounded torus visualization |
| [Wounded Torus Fold](https://raggedr.github.io/symmetric-graphs/bolza-surface/wounded_torus_fold.html) | Wounded torus folding animation |

## Mathematics

See [MATHEMATICS.md](MATHEMATICS.md) for the algebraic geometry background: lattice quotients, Weierstrass ℘-function, Eisenstein series, and the Bolza surface as a quotient of the hyperbolic plane.

## Stack

Three.js, vanilla JavaScript, Python (SageMath for group computations).
